⟳ IN PROGRESS EMBEDDED SYSTEMS TELEMETRY CONTROL SYSTEMS

01. Objective

Design and build a two-axis auto-tracking antenna mount for the RMIT HIVE Rocketry team. During rocket launches, the system must automatically point a directional antenna toward the rocket in real time — maintaining line-of-sight for telemetry reception across the full flight envelope.

The system receives GPS telemetry from the rocket's onboard flight computer, calculates the required azimuth and elevation angles using the ground station's known GPS coordinates, and drives servo or stepper motors to continuously re-point the antenna.

02. Technology Used

Computing & Control
ESP32 (main controller) PlatformIO / C++ PID Control Loop
Sensors & GPS
NEO-M8N GPS Module (ground station) LoRa RFM95W (telemetry receive) IMU / Magnetometer (mount heading reference)
Actuation
Azimuth: Stepper Motor + Belt Drive Elevation: High-Torque Servo Custom Pan-Tilt Mount (3D Printed)
Comms
LoRa 915MHz (rocket telemetry link) UART (GPS NMEA stream)

03. How It Works

Telemetry Receive: The rocket broadcasts GPS coordinates and altitude via LoRa at regular intervals. The ground station's RFM95W module receives each packet and decodes the rocket's position.

// Angle calculation from GPS coordinates Δlat = rocket_lat - ground_lat Δlon = rocket_lon - ground_lon Δalt = rocket_alt - ground_alt azimuth = atan2(Δlon, Δlat) → compass bearing (°) elevation = atan2(Δalt, horiz_dist) → look-up angle (°)

Pointing Control: Computed azimuth and elevation angles are fed into a PID control loop that drives the azimuth stepper and elevation servo to minimise the angular error. The magnetometer provides the mount's current heading so the azimuth reference is absolute (not relative to startup orientation).

MVP Scope: The current build targets the minimum viable system for a launch campaign — reliable tracking within ±5° during flight, with manual override capability.

05. Challenges

Magnetometer Interference Near Motors

The stepper motor's magnetic field corrupts the magnetometer heading reading when mounted nearby. Physical separation and magnetic shielding are being evaluated — alternatively, a compass-calibration routine that runs before motor power is applied.

LoRa Packet Loss at High Elevation Angles

At very high elevation (rocket directly overhead), the directional antenna gain drops — the system needs to handle momentary packet loss gracefully with dead-reckoning from the last known trajectory.

Coordinate Frame Conventions

Mixing up NED vs ENU coordinate frames caused the azimuth calculation to point 90° off on the first test. Explicitly documenting and enforcing one coordinate convention throughout the codebase fixed this permanently.
