CategoryDetails
MicrocontrollerESP32-C3 SuperMini - RISC-V, 160MHz, 4MB Flash, WiFi 802.11 b/g/n
FirmwareC++ / Arduino Framework, PlatformIO, LovyanGFX, WiFi AP Mode, WebServer
DisplayST7789V 1.14 inch TFT (135x240) - 3-screen UI via LovyanGFX over hardware SPI
Current SensorACS712-5A Hall-effect on solar input line, calibrated offset 0.661V
Voltage MonitorResistor voltage divider, battery pack voltage, empirical ratio 23.0
Env SensorDHT22 temperature and humidity, 2s boot stabilisation required
Relays2x relay modules - Relay 1: load control, Relay 2: charge control
Power5W 12V solar + USB-C 5V, XL4015 boost to 12.6V, 3S 18650 BMS
ConnectivityWiFi AP Mode - SSID: SolarMonitor, IP: 192.168.4.1, no router required
// Engineering Challenges
01 - GPIO9 Strapping Pin Unusable

GPIO9 is a strapping pin tied to boot mode - cannot be driven LOW as software output.

SOLUTION: Physical slide switch on 5V fan power line.
02 - ADC1 Pin Shortage

Only ADC1 channels exposed on ESP32-C3 SuperMini. No free ADC1 pin for solar voltage.

SOLUTION: ADS1115 I2C ADC planned for v2.
03 - Relay Boot Flicker

GPIO pins float briefly before Arduino init, causing momentary relay energisation.

SOLUTION: ESP-IDF gpio_reset_pin before Arduino pinMode.
04 - ACS712 Zero-Current Offset Drift

Consistent -1.77A reading at zero current due to supply variation.

SOLUTION: Midpoint corrected to 0.661V with deadband filter.
05 - DHT22 NaN on First Read

Sensor returns NaN without stabilisation period after power-on.

SOLUTION: 2-second delay between Serial.begin and dht.begin.
// Results
Real-time monitoring of current, voltage, power, temperature, and humidity.
Web dashboard live at 192.168.4.1 - relay control from any device, no router required.
Relay automation confirmed - load disconnect below 10.5V.
ACS712 stable at 0.00A no-load. Battery voltage accurate to 0.1V.
TFT smooth - no ghosting across 3-screen navigation. All touch gestures functional.
