PROJECT: OUSB_SIMULATOR

01. Objective

The objective of this project was to develop a high-fidelity hardware simulator in C++ that monitors the behaviour of an OUSB (Open USB) board. The goal was to create a functional software environment where digital logic and register manipulations could be tested without physical hardware.

02. Technology Used

C++ AVR Architecture Register-Level Logic Bitwise Operations File I/O Parser

03. The Challenges

The main challenge was emulating the Register-Level Logic of the AVR architecture used in OUSB boards. I had to ensure that software instructions correctly manipulated virtual pins and ports in the exact sequence the hardware would. Another significant hurdle was managing Error Precedence. In a hardware environment, certain errors (like invalid port access) must be caught and reported in a specific order of priority to prevent the simulator from crashing or providing false data. Finally, I had to implement a way to handle File I/O so that the simulator could read a list of hardware commands from a text file and execute them in real-time.

04. The Solutions

To solve the register challenge, I used C++ classes to represent the hardware ports (Port B, Port D, etc.) and implemented Bitwise Operations to handle the masking and setting of individual pins. This allowed the software to mimic the "High" and "Low" states of a physical circuit. For error management, I developed a robust validation engine that checks for instruction syntax and hardware constraints before execution, ensuring the simulator follows strict "Fail-Safe" protocols.

To handle the command execution, I built a custom Parser that reads external files, translates the strings into hardware instructions, and updates the virtual registers accordingly. I also integrated a feedback loop that outputs the state of the "LEDs" and "Switches" to the console, providing a visual representation of the virtual hardware state.

05. Results

✅ The simulator is fully functional and accurately mirrors the behaviour of a physical OUSB board. It successfully handles complex instruction sets and reports errors with 100% accuracy according to the hardware specification. This project demonstrated my ability to bridge the gap between high-level C++ programming and low-level hardware logic, providing a reliable tool for debugging embedded software.
